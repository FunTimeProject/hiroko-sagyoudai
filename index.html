ひろ子 作業台 / Hiroko Workbench

ひろ子 作業台は、YouTube チャンネル「ひろ子の宇宙倶楽部」の運営者が、自分のパソコンの中だけで使う動画づくりの道具です。一般の人に向けて配ったり、販売したりはしていません。

この道具でできること：

  • 動画の台本、タイトル、概要欄、タグ、サムネイルを準備する
  • 運営者自身の YouTube チャンネルに、完成した動画とサムネイルを「非公開・予約公開」でアップロードする

YouTube との連携には YouTube API Services を使っています。使う権限は、動画とサムネイルのアップロード（youtube.upload）だけです。

Hiroko Workbench is a private desktop tool used only by the operator of the YouTube channel "ひろ子の宇宙倶楽部" (Hiroko's Space Club) on the operator's own computer. It is not distributed or sold to the public.

What it does:

  • Prepares scripts, titles, descriptions, tags and thumbnails for the channel's videos
  • Uploads finished videos and thumbnails to the operator's own YouTube channel as private videos with a scheduled publish time

It uses YouTube API Services. The only permission requested is uploading videos and thumbnails (youtube.upload).
